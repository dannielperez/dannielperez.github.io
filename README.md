# dannielperez.github.io

The source for [Danniel Perez’s personal site](https://dannielperez.github.io): a playful collection of code, notes, experiments, and internet ephemera.

## What’s here

- A responsive editorial/terminal-inspired homepage
- A Jekyll-powered writing archive
- Links to [GitHub](https://github.com/dannielperez) and [LinkedIn](https://www.linkedin.com/in/dannielperez/)
- Small interactive touches, including a live Puerto Rico clock and randomized status messages

## Local development

This is a Jekyll site hosted with GitHub Pages. Install the dependencies and run:

```bash
bundle exec jekyll serve
```

Then open `http://localhost:4000`.

The site began with the MIT-licensed Beautiful Jekyll theme and has since been extensively customized.
